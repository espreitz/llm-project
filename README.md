# LLM Project

In this project, I used an LLM (ChatGPT's codex tool) to create an interactive, user-friendly snowman game out of my previous snowman project code.
##  Key features and extensions

In my snowman interface, I included all the elements of my original snowman game, plus a few others:
1. Extra words in the existing word bank, plus an additional word bank that contains easier words
2. A function that allows you to create your own word
3. A revised point system (now includes rounds of 3, and a high-score table)
4. A surrender button
5. A feature that allows you to look at the contents of a word bank

## Challenges I Ran Into

While prompting my LLM to build my game, I ran into a few challenges. One of these problems was that the Codex tool made an error with the guess count system, allowing you to ask for and receive a hint even when you didn't have enough guesses remaining. It then allowed you to keep guessing until you reached -2 guesses remaining. I fixed this by letting the LLM know what was wrong and that it should fix the problem.

## What I'd Improve With More Time

If I had more time to work on this project, I would revise the interface to make it appear more minimalistic and organize the word banks in a different tab of the game. I would also add a few additional words, and revise the scoring system to give penalties as well as bonuses.
